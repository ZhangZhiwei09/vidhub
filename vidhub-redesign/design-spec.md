# VidHub 全站重设计 · Design Spec

> 共同输入给三套逻辑。三方向都在「苹果风格」语境内做差异化诠释；选定后才落到 Next.js 实站。

## 产品是什么

**VidHub** 是一个自托管视频分享站（Next.js + PostgreSQL），同时包含：

- **用户端**：首页 feed、分区筛选、热门、搜索、视频详情（含弹幕）、投稿上传、直播大厅、私信、通知、个人空间（作品/收藏/关注/粉丝）、账号设置、登录注册
- **管理端**：仪表盘、视频审核、用户管理、评论管理、弹幕管理

它不是营销落地页，是**日活产品界面**：浏览密度高、封面图是内容主角、导航与状态反馈必须清晰。设计目标是让整站读起来像「苹果做的视频社区」——克制、内容至上、材质与字距讲究——而不是再做一个紫渐变 SaaS 壳。

## 目标受众与使用场景

- **观众**：桌面为主、偶尔手机；快速扫封面 → 点进播放 → 发弹幕/评论
- **创作者**：投稿、看数据、管理作品；需要冷静可信的工具感
- **管理员**：审核队列、统计卡片；信息密度高于用户端，但不能脏乱

场景距离以 **1m 笔记本主视距** 为主，管理端略偏高密度。

## 核心信息与内容板块（初稿页面必须覆盖）

每个方向的 HTML 初稿至少展示同一套内容骨架，只换视觉逻辑：

1. **顶栏 / 导航**：VidHub 品牌、首页/热门/搜索/投稿/直播/消息、登录态
2. **首页**：一句品牌宣言 + 主 CTA（去投稿 / 热门）+ 分区 tabs（全部 / 动画 / 音乐 / 游戏 / 科技 / 生活 / 娱乐等）+ 视频卡片网格（封面、标题、UP 主、播放量）
3. **管理端一瞥**：侧栏或顶部分区导航 + 仪表盘数字卡（待审视频、用户、评论、弹幕等）
4. **可点交互**：分区切换高亮、卡片 hover、管理端 tab 切换、登录按钮态（原型级，不接后端）

文案使用真实中文产品语，禁止 Lorem：

- 品牌：VidHub
- Hero：「发现精彩视频」/ 各方向可微调语气，但信息不变
- 副文：「列表、详情与分片投稿已接入。登录后即可上传。」
- 分区名沿用产品：全部、动画、音乐、游戏、科技、生活、娱乐…（以 `PARTITIONS` 为准）
- 示例片：用取到的真图作封面；标题写像真实投稿的中文名

## 情感基调与气质关键词

用户指定：**喜欢苹果的风格**。

关键词：克制、内容至上、精密字距、材质感（玻璃/磨砂/暗房）、少装饰、单 accent、交互丝滑但不花哨。

禁止：紫渐变 SaaS、emoji 图标墙、粗描边 Neo-Brutal 卡片、GitHub-dark+霓虹 glow 偷懒解、Inter 当唯一 display（除非该方向明确用系统栈）。

## 输出格式与尺寸（三版统一）

- **形态**：可点击单文件 HTML 原型（首页 + 管理端切换），纯 HTML/CSS + 少量 inline JS
- **视口截图**：1440×900
- **存放**：`vidhub-redesign/design-demos/[逻辑名].html`
- **不是**生产 Next.js 改动——方向选定后再进实站

## 已知约束

- 品牌资产：用户说「你看着办」——无 logo 文件、无 VI。自定：词标 **VidHub** + Apple Blue 系 accent `#0071E3`（或各方向论证后的变体），不伪造苹果 logo
- 范围：用户端 + 管理端全站视觉语言；初稿用「首页 + 管理仪表盘」代表全站 grammar
- 生产系统有后端：本阶段只定视觉/交互 grammar，不改 API
- 反 slop：三版骨架必须结构性互异（导航/构图/内容区至少一项不同）

## 图片需求（Phase 3.5）

内容必需：视频封面。策略：Unsplash 免版权电影/舞台/创作场景图，本地路径或 base64；三版共用同一批封面，只换设计。

## 视觉母题假设（form 种子）

VidHub 独有母题不是「又一个视频网格」，而是 **「一块发光的矩形屏幕被干净的边框托住」**——像苹果把产品放进负空间：封面是发光体，UI 是几乎消失的裱框。三方向用不同方式诠释这块「屏幕」：

- 暗房裱框 / 营销大字报 / 系统材质工具台

## Form 五问（统一答案，实现各异）

1. **叙事角色**：首页 = hero + 内容流；管理端 = 数据台
2. **观众距离**：1m 笔记本
3. **视觉温度**：冷静 + 一点精致兴奋（点进视频时）
4. **容量**：首屏品牌区不宜堆 stats；下方 8–12 张卡
5. **视觉母题**：发光矩形屏幕 / 内容裱框

## 三方向锚点（执行时填写）

| 逻辑 | 锚点 | 苹果语境诠释 |

## Assumptions（已标）

- 无官方 logo 文件 → 使用精致词标，不画假苹果标
- 分区列表以 shared `PARTITIONS` 为准；若取图未齐，封面用诚实渐变块 + 标题
- 初稿交互为原型级；选定后映射到 Tailwind/React 组件
